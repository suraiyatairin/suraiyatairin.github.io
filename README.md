# Suraiya Tairin — academic website

Open index.html to preview. Edit index.html for content and style.css for appearance. No installation or build is needed.

## GitHub Pages publishing

1. Sign in to GitHub and find your exact username on your profile.
2. Create a public repository named USERNAME.github.io, replacing USERNAME with your username. If it already exists, inspect its content before replacing files.
3. Upload index.html, publications.html, academics.html, teaching.html, experience.html, service.html, style.css, the img folder, and .nojekyll directly to the repository root, not inside another folder, and commit to main. The upload UI may hide .nojekyll; the two main files can work without it for this plain HTML site.
4. Go to Settings → Pages → Build and deployment. Choose Deploy from a branch, then main and / (root), and Save.
5. Visit https://USERNAME.github.io/ once deployment completes. Publication can take up to 10 minutes.

Official guide: https://docs.github.com/en/pages/quickstart
